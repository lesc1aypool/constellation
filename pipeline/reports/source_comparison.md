## How to read this

- **●** and bold = the artist appears in both lists.
- **⚠** = no MusicBrainz ID in that result (we'd have to match by name, which is error-prone).
- ListenBrainz score = raw co-listening strength (bigger is stronger; not 0–1). Last.fm score = match from 0 to 1.
- ListenBrainz algorithm: `session_based_days_7500_session_300_contribution_5_threshold_10_limit_100_filter_True_skip_30` (the one their website uses).
- Popularity: ListenBrainz users = distinct ListenBrainz users who played the artist; Last.fm listeners = distinct Last.fm listeners. Last.fm's user base is far larger.
